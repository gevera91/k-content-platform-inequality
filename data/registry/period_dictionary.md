# Period Dictionary

## 2026-03-28

본 문서는 `Prompt 05` 기준으로 프로젝트 전체의 기간 표기 규칙을 고정한다. 이 문서 이후에는 새로운 기간 문자열이나 임의 형식을 추가하지 않는다.

## 1. 기본 원칙

- 모든 날짜는 그레고리력 기준으로 저장한다.
- 구분자는 하이픈 `-`만 사용한다.
- 월과 일은 항상 두 자리로 고정한다.
- 원자료가 현지 언어로 제공되더라도 저장 시점에는 아래 표준 형식으로 변환한다.
- `panel_platform_month`는 `year_month`를, `panel_platform_quarter`, `panel_title_quarter`, `panel_sector_quarter`는 `year_quarter`를 기본 키로 사용한다.

## 2. 표준 변수와 형식

| 변수명 | 형식 | 예시 | 정의 |
|---|---|---|---|
| `date` | `YYYY-MM-DD` | `2026-03-28` | 실제 사건일, 공표일, 수집일 등 일 단위 날짜 |
| `year` | `YYYY` | `2026` | 연 단위 자료의 기준 연도 |
| `year_month` | `YYYY-MM` | `2026-03` | 월 단위 분석과 병합용 표준 키 |
| `month_id` | `YYYYMM` | `202603` | 파일명 또는 정렬용 숫자형 문자열 |
| `year_quarter` | `YYYYQn` | `2026Q1` | 분기 단위 분석과 병합용 표준 키 |
| `quarter_id` | `YYYYQn` | `2026Q1` | `year_quarter`와 동일하며 보고서용 별칭으로만 사용 |
| `quarter_start_date` | `YYYY-MM-DD` | `2026-01-01` | 해당 분기의 시작일 |
| `quarter_end_date` | `YYYY-MM-DD` | `2026-03-31` | 해당 분기의 종료일 |
| `access_date` | `YYYY-MM-DD` | `2026-03-28` | 웹페이지 또는 파일 실제 접근일 |

## 3. 월과 분기 매핑 규칙

- 1월~3월은 `Q1`
- 4월~6월은 `Q2`
- 7월~9월은 `Q3`
- 10월~12월은 `Q4`
- 월 자료를 분기로 올릴 때는 동일 분기 내 월값을 평균 또는 합계로 집계하되, 어떤 방식을 썼는지는 파생 파일의 메타데이터에 반드시 기록한다.

## 4. 회계연도와 달력연도 처리

- 공시자료에 회계연도와 달력연도가 다를 경우 원자료의 `fiscal_year`와 `fiscal_quarter`는 별도 보존한다.
- 분석용 패널에는 반드시 달력 기준 `year_quarter`를 추가 생성한다.
- 회계분기를 달력분기로 옮길 때는 보고기간 종료월을 기준으로 귀속 분기를 정한다.
- 연간 자료는 별도 배분 근거가 없으면 월 또는 분기로 기계적 분할하지 않는다.

## 5. 결측과 부분기간 규칙

- 일자가 없는 월 자료는 `date`를 임의 생성하지 않고 `year_month`만 채운다.
- 월 정보가 없는 연간 자료는 `year`만 채우고 `year_month`, `year_quarter`는 공란으로 둔다.
- 범위형 자료는 시작일과 종료일을 별도 열로 보존하고, 단일 키는 대표 기간을 임의 생성하지 않는다.
- 분기 또는 월이 불명확한 자료는 억지로 가장 가까운 기간에 넣지 않고 `notes`에 원문 표현을 남긴다.

## 6. 금지 규칙

- `2026/3`, `2026.03`, `2026-Q1`, `Q1-2026`, `Mar-2026` 같은 표기는 저장하지 않는다.
- 새로운 `country_std`, `firm_std`, `service_std`와 마찬가지로 새로운 기간 포맷도 임의 생성하지 않는다.
- Excel 직렬일자나 로케일 기반 날짜 표기를 원본 그대로 보관하지 않는다.

## 7. 예시

- `2026년 3월` -> `year_month = 2026-03`
- `2026년 1분기` -> `year_quarter = 2026Q1`
- `FY2025 4Q` 공시 종료일이 `2025-12-31`이면 분석용 `year_quarter = 2025Q4`
- `2025 annual report`만 존재하면 `year = 2025`만 사용하고 월·분기를 채우지 않는다
