# v1.0.0 — 한국어 최종보고서와 공개 재현 패키지

전성민·강형구의 「K-콘텐츠 플랫폼 생태계의 구조적 불평등 계량화 및 정책 대안 연구」 2026년 10월 27일 개정본과 재현 자료를 공개합니다.

## 포함 자료

- 최종 한국어 보고서 PDF 168쪽과 TeX·그림 소스
- 고정 분석 데이터·레지스트리·결과표·그림 289개 파일(그중 CSV 260개)
- 환경 경로를 정리한 분석 코드, 고정 Python 의존성, 전체·core 재현 실행 도구
- CPII 기업 비교기 v2 XLSX와 입력 템플릿
- [공개 Google Sheets 비교기](https://docs.google.com/spreadsheets/d/1qrbtViewFJKwZeBRDOmfXA8kzCt3vyrlDmGcW93DgTY/edit)
- 데이터 사전, 원천 링크, 계산 검증 기록과 SHA-256 체크섬

## 재현 검증

새 Python 3.12 환경에서 전체 15개 계산 단계를 실행했습니다. 기준 CSV 49개, 수치 셀 75,305개, 보고서 핵심 확인사항 20개와 테스트 83개가 모두 통과했습니다. Core 실행은 CSV 29개와 수치 셀 28,432개를 확인했습니다.

전체 패키지를 내려받은 뒤 README의 설치·실행 절차를 따르세요. Google Sheets는 열람용 원본을 개인 사본으로 복사하여 사용할 수 있습니다. 동봉 기업과 비교기준은 합성 예시이며, 보고서의 실제 기업 비교사례와 구분되어 있습니다.
