# Google Sheets 시뮬레이터 사용 안내

[공개 CPII 기업 비교 시뮬레이터 열기](https://docs.google.com/spreadsheets/d/1qrbtViewFJKwZeBRDOmfXA8kzCt3vyrlDmGcW93DgTY/edit)

[GitHub 공개 재현 저장소](https://github.com/gevera91/k-content-platform-inequality) · [최종 한국어 보고서 PDF](https://github.com/gevera91/k-content-platform-inequality/blob/main/reports/kakao_enter.pdf) · [v1.0.0 고정 릴리스](https://github.com/gevera91/k-content-platform-inequality/releases/tag/v1.0.0)

공개 시트는 링크가 있는 누구나 읽을 수 있다. 직접 실험하려면 Google 계정으로 로그인한 뒤 **파일 → 사본 만들기**를 선택하여 개인 사본에서 입력값을 변경한다. 공개 원본의 열람·다운로드·복사·인쇄가 허용되어 있다.

이 시트는 저장소의 [Excel 통합문서](../spreadsheet/CPII_Company_Comparator.xlsx)를 Google Sheets 형식으로 변환한 별도 공개본이다. 14개 시트, 수식, 두 비교 차트, 네 개 표를 유지했다. 정해진 선택지가 있는 12개 표 열은 Google Sheets 드롭다운으로 표시된다. 변환 후 기여도 차트의 위치와 높이를 조정하여 두 차트가 겹치지 않도록 했다.

## 먼저 기본값을 재현한다

`03_COMPARE_2`에서 회사 A가 `SYN-A`, 회사 B가 `SYN-B`인지 확인한다. 다음 결과는 **가상 기업의 합성 예시**다.

| 항목 | 관측 ID | 계산값 |
|---|---|---:|
| 가온 콘텐츠 CPII | SYN-A | 39.89561107334345 |
| 누리 미디어 CPII | SYN-B | 32.21744929663617 |
| A−B 차이 | SYN-A − SYN-B | 7.6781617767072845 |

화면에는 소수 둘째 자리로 표시되므로 각각 `39.90`, `32.22`, `7.68`로 보인다. 반올림 전 값으로 검증한다. `99_QA_AUDIT!D7:D18`의 12개 검사가 모두 `PASS`인지 확인한다. 공개 시점의 Python 기준값 대비 최대 절대오차는 `1.42×10⁻¹⁴`로 허용치 `10⁻¹⁰`보다 작다.

## 개인 사본에서 실행하는 순서

1. `00_README`에서 입력·계산 시트의 구분과 방법론 버전을 확인한다.
2. `01_INPUT_COMPANIES`의 파란 입력 셀에 회사별 관측값과 비교조건을 입력한다. 한 행은 기업–서비스–시장–분기 관측이다. 필수 변수 10개를 채우고, 비율 1%는 `0.01`, 3배는 `3`으로 입력한다. 빈칸과 0을 구별한다.
3. `07_INPUT_PROVENANCE`에 각 변수의 출처, 기준일, 구축방식을 기록한다. 금액 해석이 필요하면 `02_INPUT_ECON_BASES`도 입력한다.
4. `03_COMPARE_2!B4:B5`에서 서로 다른 두 관측 ID를 선택한다. 비교상태가 `비교 가능`이면 총점, 하위지수, 변수별 기여도를 확인한다. 차이는 **A−B**이며, 양수는 A의 부담지수가 더 높다는 뜻이다.
5. `04_COMPARE_N`에서 동일 비교집단 안의 순위와 차이를 확인한다. 최대 100개 관측을 계산하며, 차이 행렬은 앞의 30개 관측을 표시한다.
6. `05_ECON_INTERPRET`에서 채널별 조건부 상당액과 시나리오 금액을 확인한다. 서로 겹치는 경제 채널의 금액은 합산하지 않는다.
7. `06_SENSITIVITY`의 네 가지 방법론 사양과 `99_QA_AUDIT`의 입력·계산 검증 결과를 확인한다.

넓은 표와 오른쪽 차트는 가로 스크롤로 볼 수 있다. `90_CALC_FEATURES`부터 `94_EXPECTED_OUTPUTS`까지는 계산·참조 시트다. 수식이나 기준값을 덮어쓰지 않는다. 새 입력으로 예시를 바꾸면 원본 예시 대조 대신 `READY` 등이 표시될 수 있다. 변경 후 상태의 의미는 [상세 사용 안내](../spreadsheet/CPII_Comparator_User_Guide.md)의 “비교조건과 검증”을 따른다.

## 합성 예시와 실제 기업 분석의 구분

기본 시트의 네 회사는 가온 콘텐츠·누리 미디어·다온 스토리·라온 플레이이며, 등록 비교기준 `BM-DIGITAL-CONTENT-2025Q4`도 합성 예시 전용이다. **이 기본값은 멜론·스포티파이의 추정 결과가 아니다.** 회사명만 바꾸어 실제 기업 분석으로 사용할 수 없다.

실제 기업을 분석하려면 비교 가능한 산업·서비스·시장·분기의 입력자료와 변수별 출처를 확보하고, 실제 비교기준을 등록한 뒤 통합문서를 다시 생성한다. 절차와 명령은 [상세 사용 안내](../spreadsheet/CPII_Comparator_User_Guide.md)의 “실제 비교기준 등록”과 저장소의 재현 안내를 참조한다. 이 Sheet에서 자료를 수정했다고 저장소의 데이터나 보고서가 자동 갱신되지는 않는다.

`06_SENSITIVITY`는 네 가지 방법론 사양을 비교한다. 기본 예시의 차이는 `6.398932–8.788157`점이고 네 사양에서 모두 양수다. 입력값의 하한·기준·상한에 따른 분석은 Python의 `--feature-ranges` 절차로 별도 실행한다. 두 결과는 각각의 설정을 바꾸어 계산한 범위다.

## 버전과 검증 기록

공개·검증일은 2026년 10월 27일이다. Google Sheets 공개본은 편리한 실행 경로이고, 정확한 버전을 보존하는 기준은 저장소의 XLSX·코드·데이터다. 연구 결과를 공유할 때 사용한 저장소 커밋과 개인 사본의 입력 변경사항을 함께 기록한다.

최초 공개본을 재현할 때는 **v1.0.0 고정 릴리스**의 코드·데이터·XLSX·PDF를 함께 사용한다. `main`의 최신 보고서와 릴리스 고정본을 구분한다. 공개 시트의 `00_README!A41:H45`에도 저장소·보고서·릴리스 링크와 같은 안내가 있다.

접근 권한, 전체 시트 목록, 기본 계산값, 원본 XLSX의 SHA-256은 [공개 검증 기록](../publication/gsheet_publication.json)에 있다. 보고서의 시뮬레이터 부록과 [상세 사용 안내](../spreadsheet/CPII_Comparator_User_Guide.md)는 변수 정의와 해석 방법을 설명한다.
